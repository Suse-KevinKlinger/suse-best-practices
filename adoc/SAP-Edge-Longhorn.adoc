[#suse-storage]

== Installing {lh}

To deploy the chart, create the related namespace and *imagePullSecret* first.
To create the namespace, run:

[source, bash, subs="attributes"]
----
kubectl create namespace {lh}
----

[#redisIPS]
Instructions how to create the *imagePullSecret* can be found in <<imagePullSecret>>.

[#longhornLIR]
Before you can install the application, you need to log in to the registry. 
You can find the instructions in <<LoginApplicationCollection>>.

Create a _values.yaml_ file with the following configuration:

[source,yaml]
----
global:
  imagePullSecrets:
    - name: application-collection
----

Then install the {lh} application:
[source, bash, subs="attributes"]
----
helm install longhorn oci://dp.apps.rancher.io/charts/suse-storage \
  -f values.yaml \
  --namespace longhorn-system \
  --version {lh_version}
----

For more details, visit https://documentation.suse.com/en-us/cloudnative/storage/.
